# ArchaismOk

A GTK3 theme and an icon theme, both named ArchaismOk, that faithfully
recreate the look of Fedora 12 (GNOME 2.28, Clearlooks, Mist icons).
Target desktop: MATE on X11.

## Layout

- `icons/` — icon theme build. `sources/` holds the extracted themes
  (`*.12` from Fedora 12, `*.new` from Arch's gnome-icon-theme and AUR Mist).
- `theme/` — GTK theme, forked from Clearlooks-Phénix (GPL-3, see
  `theme/COPYING`; upstream notices in `theme/UPSTREAM.md`). Main files:
  `gtk-3.0/gtk.css` (colors, imports), `gtk-3.0/gtk-widgets.css`,
  `gtk-3.0/mate-applications.css`; `_src/` holds SVG sources for
  `gtk-3.0/img/` (rebuild with `make -C theme/_src`, needs Inkscape;
  the combo arrow SVGs are generated by `theme/_src/combo-arrow.py`, a port
  of the Clearlooks engine drawing code, and rendered with rsvg-convert).

## Icons

- Build: `python3 icons/build.py` — writes `icons/ArchaismOk/` and
  `icons/report.html`. Needs Pillow and NumPy. The build asserts that every
  output icon matches its chosen source; there is no other test.
- Pick icons: `python3 icons/serve.py`, open the printed URL, click icons to
  take the new artwork. Picks go to `icons/prefer-new.txt` (one name per
  line, also hand-editable); rerun build.py to apply. Stop the server with
  Ctrl-C, or the next start reports the port as busy.
- Package (on Arch, after build.py): `cd icons && makepkg -f`, then
  `sudo pacman -U archaismok-icons-*.pkg.tar.zst`.

## Theme

- Try it without packaging: copy or symlink `theme/` to
  `~/.themes/ArchaismOk`, then select it in MATE Appearance. GTK3 apps
  need a restart to pick up CSS changes; `GTK_DEBUG=interactive <app>`
  opens the inspector to find which CSS rule styles a widget.
- Package (on Arch): `cd theme && makepkg -f`, then
  `sudo pacman -U archaismok-gtk-theme-*.pkg.tar.zst`.

## Reference sources (not in git)

`reference/` holds GNOME 2 era sources matching Fedora 12, for looking up
how Clearlooks really drew things. Fedora 12 itself (VM screenshots) has the
final say where they disagree, since Fedora may have patched these.

- `gtk-engines-2.18.4` — Clearlooks engine (`engines/clearlooks/src/`,
  drawing in `clearlooks_draw.c`) and its gtkrc
  (`themes/Clearlooks/gtk-2.0/gtkrc`).
- `gnome-themes-2.28.1` — Clearlooks Metacity theme, Mist icons.
- `gtk+-2.18.9` — GTK2 widget structure and default metrics.

Recreate with (sha256 files come from the same directory):

    mkdir -p reference/tarballs && cd reference/tarballs
    B=https://download.gnome.org/sources
    curl -LO $B/gtk-engines/2.18/gtk-engines-2.18.4.tar.bz2
    curl -LO $B/gnome-themes/2.28/gnome-themes-2.28.1.tar.bz2
    curl -L $B/gtk+/2.18/gtk%2B-2.18.9.tar.bz2 -o gtk+-2.18.9.tar.bz2
    cd .. && for t in tarballs/*.tar.bz2; do tar -xjf "$t"; done

## Format

- Python: `ruff format` and `ruff check` (config in `ruff.toml`).
